# ADR-010: FastAPI REST + OpenAPI-generated TS client + SSE
**Status:** Proposed

## Decision
- Resource-oriented REST under `/v1`, JSON bodies, RFC 9457 problem+json errors with stable `code`s.
- The OpenAPI 3.1 document is generated by FastAPI. The web client is generated with `openapi-typescript` + `openapi-fetch`.
- Realtime events go over SSE at `/v1/orgs/{orgId}/events`.
- `Idempotency-Key` is required on mutating financial endpoints.
- Pagination is cursor-based.

## Alternatives
- GraphQL: not needed; adds complexity in authorization.
- gRPC: browser support.
- WebSockets: SSE is enough (server→client).

## Consequences
Breaking API changes require a `/v2` path or additive fields.
